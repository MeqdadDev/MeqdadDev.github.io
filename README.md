# Meqdad Darwish — Portfolio

Static site (HTML, CSS, vanilla JS). No build step. Published at https://meqdaddev.github.io/

The full résumé lives in its own repo/site: https://meqdaddev.github.io/resume/

## Run locally

    npx serve .

then open http://localhost:3000 (or the port `serve` prints).

## Structure

- `index.html` – single-page portfolio
- `styles.css`, `script.js` – styling, theme toggle, carousel, email CTA
- `assets/` – optimized WebP/SVG images and the social preview image
- `favicon-32.png`, `favicon-192.png` – circular favicon / touch icon
